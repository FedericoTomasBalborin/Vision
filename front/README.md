# Vision Frontend

This folder contains the React dashboard used to interact with the Vision platform.

## What the frontend does

The frontend is the user-facing layer of the application. It allows users to:

- choose a store
- upload a sales workbook
- filter by date range
- view revenue and sales KPIs
- inspect top products and product profitability
- browse data tables and product catalogs
- trigger sales predictions generated by the backend
- switch between metrics, predictions, and raw data views

## Stack

- React + TypeScript
- Vite
- Tailwind CSS
- shadcn/ui components
- Recharts for charts and visualizations
- React Query for API-friendly state handling

## Main responsibilities

- Render the dashboard shell and navigation
- Call the FastAPI backend endpoints in [back/](/Users/fedeb/OneDrive/Documentos/Vision-1/back)
- Display summary metrics and charts using imported data
- Show the prediction tab for store forecasting
- Manage local UI state for store selection, filters, and view mode

## Development

```powershell
cd front
npm install
npm run dev -- --host 0.0.0.0 --port 8080
```

The app expects the backend to be available at:

```text
http://127.0.0.1:8000
```

## Typical workflow

1. Start the backend and database.
2. Start the frontend.
3. Select a store.
4. Upload a sales Excel file.
5. Explore metrics or generate a sales forecast.

The frontend does not perform the heavy data processing itself; it acts as the dashboard and API client for the backend.
